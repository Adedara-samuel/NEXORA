# NEXORA Payment Worker

BullMQ + Redis background worker for payment-provider webhook processing,
wallet ledger reconciliation, and subscription payment verification
(architecture sections 23, 36, 52).

**Not started.** Built starting **Phase 3 (Module + Subscription Engine)**
for subscription payment verification, and extended in **Phase 6 (NEXORA
PAY)** for wallet/payroll payment reconciliation.
